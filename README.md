# DocFlow

AI document processing: upload invoices, receipts and purchase orders; DocFlow classifies them, extracts structured data with a vision LLM, validates it with a tool-using agent, routes low-confidence fields to a human reviewer, and exports approved data.

> Work in progress. See [specs/](specs/) for the spec-driven plan, starting with the [constitution](specs/constitution.md) and the [architecture overview](specs/000-architecture/overview.md).
